## 4주차 2단계 - 페이지네이션

### 기능 요구 사항
1. 상품과 위시 리스트 보기에 페이지네이션을 구현

### API 명세
| URL                                       | 메서드 | 기능        | 설명                                |
|-------------------------------------------|-----|-----------|-----------------------------------|
| `/api/products?page=0&size=2&sort=id,asc` | GET | 상품 조회     | 상품 전체를 페이지네이션하여 조회한다.             |
| `/api/wishes?page=0&size=2&sort=id,asc`   | GET | 위시 리스트 조회 | 로그인 된 사용자의 위시 리스트를 페이지네이션하여 조회한다. |

## 4주차 3단계 - 상품 옵션

### 기능 요구 사항
1. 상품 정보에 옵션을 추가
    - 상품에는 항상 하나 이상의 옵션이 있어야 한다.
    - 옵션 이름은 공백을 포함하여 최대 50자까지 입력할 수 있다.
        - 특수 문자
            - 가능: ( ), [ ], +, -, &, /, _
            - 그 외 특수 문자 사용 불가
    - 옵션 수량은 최소 1개 이상 1억 개 미만이다.
    - 동일한 상품 내의 옵션 이름은 중복될 수 없다.
2. 상품 옵션의 수량을 지정된 숫자만큼 빼는 기능
3. (선택) 관리자 화면에서 옵션을 추가

### API 명세
| URL                                             | 메서드      | 기능             | 설명                    |
|-------------------------------------------------|----------|------------------|-----------------------|
| `/api/products/{productId}/options`             | POST     | 상품 옵션 추가    | 상품에 옵션을 추가한다.         |
| `/api/products/{productId}/options/{optionId}`  | PUT      | 상품 옵션 수정    | 기존 상품 옵션의 정보를 수정한다.   |
| `/api/products/{productId}/options/{optionId}`  | DELETE   | 상품 옵션 삭제    | 기존 제품 옵션을 삭제한다.       |
| `/api/products/{productId}/options`             | GET      | 상품 옵션 목록 조회 | 특정 상품에 대한 모든 옵션을 조회한다. |
