## 4주차 2단계 - 페이지네이션

### 기능 요구 사항
1. 상품과 위시 리스트 보기에 페이지네이션을 구현

### API 명세
| URL                                       | 메서드 | 기능        | 설명                                |
|-------------------------------------------|-----|-----------|-----------------------------------|
| `/api/products?page=0&size=2&sort=id,asc` | GET | 상품 조회     | 상품 전체를 페이지네이션하여 조회한다.             |
| `/api/wishes?page=0&size=2&sort=id,asc`   | GET | 위시 리스트 조회 | 로그인 된 사용자의 위시 리스트를 페이지네이션하여 조회한다. |
